# 采集异常修复建议

读取 `DESIGN_CONSTITUTION.md`、失败证据、对应来源适配器及历史样本。先区分网络、限速、访问限制、正常空结果、正文修订、结构和分页变化。原因不明时要求人工处理，不通过改变质量标准使失败消失。

确认为适配实现问题时，使用宿主编码能力生成最小 unified diff 补丁。只可修改对应来源 `src/ftr/adapters/<source>.py` 或该来源子目录。通过 `ftr repair prepare --failure ID --patch FILE` 提交，读取范围检查结果。当前版本不执行候选代码或候选测试；`ftr repair test` 必须返回阻塞。不要修改来源信任表、契约、测试、宪章、运行器、依赖和发布门禁，也不要因网站访问受限而伪装身份。
