# 本机定时任务与人工复核

本功能供本机本人使用，不接模型、不设团队账号。默认工作台和非回环监听仍只读。

## 打开管理入口

```sh
ftr --config /绝对路径/ftr.local.yaml workbench start --manage --open
```

已有只读工作台须先 `workbench stop` 再以上述方式启动。启动器在浏览器片段中传递两分钟有效的一次性入口，页面兑换后立即移除片段，使用 HttpOnly、SameSite=Strict Cookie。不能通过复制普通 URL 获得写权限；重启工作台使旧会话失效。不要分享管理入口。写请求须来自回环地址、同源 Origin 和有效会话，不接受跨域写入。

命令返回“等待执行”仅表示已进入持久队列。执行记录显示“执行中、已生效、失败”；失败详情中的 CONFLICT 表示预期版本过期，须刷新后重新检查。后台取得资料目录写锁后执行，业务变化和完成记录同一事务提交。与其他 CLI 冲突时等待，不删除锁或结束其他进程。

## 定时任务

基础表单设置执行时间（逗号分隔 HH:MM）、IANA 时区、含当天的回看天数；高级设置调整批次间隔及最多三次跨批等待。先预览后续四个时点与窗口，再保存。保存命令尚未执行时，以执行记录为准；应用后页面显示保存/应用版本。

有效计划保存在同一资料库 `managed_plan` 中，网页、后台和 `scheduler status/preview/run` 读取同一配置。YAML 仅作为首次缺省；存在持久计划后，修改 YAML 不能覆盖网页计划。保存新计划不会改写活动任务的冻结请求，旧补漏窗口保留。

启用表示授予定时采集权限；停用在安全检查点阻止新建与续跑并保留现场。来源暂停独立于日常计划。来源故障在处理后通过“处理后恢复来源”明确恢复，不能代替原任务的人工暂停/取消处理。来源恢复不清除原任务人工标记。

立即获取：选择财政部、税务总局中的一个或两个，预览当次窗口后确认。即使日常计划停用，也可执行明确授权的这一轮；窗口合并到同一来源待执行范围，串行复用检查点，不并发重复采集。十五分钟未执行的预览失效，需要重新预览。

后台按需启动，关闭浏览器或 `workbench stop` 后仍继续。电脑重启后需本人重新执行 `workbench start --manage --open`；启动器检测到已经授权的启用计划或待执行操作后恢复后台、检查点和补漏；没有安装开机服务。已有独立 scheduler 占用时，页面拒绝接管；请明确停止原调度器后再重试。本机管理不修改、重启 systemd。

## 资料复核

队列按“待复核、内容受限、需进一步核查、已处理”筛选，默认最新版本。可查看正文、登记原件、附件下载/解析状态、限制原因，跳转原采集任务、政策库与历史版本。

草稿单独保存，不改变资料质量。提交需填写理由、确认当前登记证据；通过仅代表采集质量符合门槛，不证明法律效力或企业适用性。硬性内容限制、正文缺失、附件未保存、证据文件缺失/摘要不符均禁止通过，可记录排除或需进一步核查。未支持的 Office/OCR 解析须进一步核查。

提交保存不可覆盖的轮次、结论、证据列表、资料快照、摘要、时间与 `local-human` 操作者。再次处理需开启新一轮，旧结论保留，现有已提交决策保持兼容。资料产生新版本或摘要变化，旧提交返回冲突，已保存草稿保留；通过政策库跳转最新版本重新检查。历史版本仅追溯，不可从旧版本通过。

补取仅限选中资料已登记的缺失正文或附件，不接受任意 URL，不扩大来源或原任务范围。成功保存新版本后重新复核。正常预算耗尽时保存部分补取版本，执行记录保持“执行中”，按批次间隔自动续取；已保存原件不重复下载。停机恢复使用原登记范围及新版本摘要校验。内容受阻时保存本批已补齐内容并显示失败与新版本入口。失败保留旧资料和草稿，在执行记录查看原因，处理后重新发起；重复下载不能解决未支持解析。没有批量通过、正文编辑或删除功能。

## 备份与故障处理

`backup create` 包含持久计划、轮次、草稿、命令队列及结果。管理会话、一次性入口、后台身份和进程日志不随备份恢复。恢复后需重新启动本机管理入口。

需检查或停止后台时，使用 `workbench background-status` / `workbench background-stop`（可带同一绝对配置路径）。停止通过认证实例控制通道请求，在安全检查点退出，不能仅凭 PID 操作。

工作台与后台的 `.workbench.json`、`.worker.json` 含私有控制能力，权限为 0600，不纳入版本库。命令文件在 `commands/`；不手工修改、删除命令、锁或身份文件。故障时先查看操作状态、任务诊断及后台日志，确认对应实例后处理。

本轮交付不启动本人真实采集、不代为复核业务资料、不安装常驻服务、不提交推送。真实来源访问、电脑重启和云端 systemd 运行须另行验收。
