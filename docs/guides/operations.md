# 运维、备份与环境迁移

运行数据与代码独立。每个数据目录仅允许一个 CLI 写入者；Web 可在采集过程中读取短事务快照。使用本地文件系统，不将多机器同时写同一个网络共享目录作为支持的部署方式。

## 数据目录内容

| 资产 | 内容与保留方式 |
|---|---|
| `database.sqlite3` | 任务、检查点、发现队列、版本、证据元数据、决策、失败与审计 |
| `evidence/` | 以 SHA-256 命名的原件；元数据使用相对路径 |
| `.runtime.lock` | 操作系统进程锁入口；文件存在不表示锁仍被持有 |
| `candidates/` | 静态修复补丁与候选说明；当前标准备份不包含此目录 |
| 外部配置、导出及研究稿 | 不在标准备份内，按需要另存 |

不要只复制数据库而丢失 evidence，不要在运行中直接复制 SQLite 主文件并忽略 WAL。标准备份使用 SQLite backup API，并在单写者锁内复制原件和生成哈希清单。

## 暂停、停止与续跑

`task pause/cancel` 可不争用采集独占锁而登记请求；采集器在检查点读取请求。命令返回 STOP_REQUESTED 后，应继续用 task status 观察状态。服务用 Ctrl+C 停止；意外退出后操作系统释放锁，锁文件无需删除。

达到页数、版本数、执行时间或字节预算时返回 PARTIAL；续跑沿用任务日期、来源、口径和任务预算，采用当前网络与浏览器参数。调整运行预算后重启命令。重复运行不覆盖历史证据或资料版本；版本复用不计为新版本。

## 备份与验证

```sh
ftr backup create --output /备份根目录/新的备份名称
ftr backup verify --path /备份根目录/备份名称
```

目标必须不存在，而且不能位于运行数据目录内。备份包含 SQLite 和 evidence，不包含候选补丁、配置、浏览器 Cookie 或虚拟环境。需要保留候选时另行复制 candidates，恢复后仍按静态候选处理。

新清单统一使用 `/` 相对路径，验证与恢复接受旧 Windows 反斜杠清单；拒绝越界路径、盘符路径、重复规范路径、符号链接以及哈希不匹配。中文、空格、`#` 及当前操作系统允许的 `?` 在文件 URI 中正确编码；Windows 文件名本身不能包含 `?`。

## 跨机器 / 跨系统迁移

1. 在原机器停止写入或使用受锁保护的 backup create；执行 verify。
2. 将备份目录整体复制到目标机器，同时单独转移非敏感配置。代理地址、凭据和浏览器路径按新环境重新设置。
3. 目标机器重新安装 Python 包、所需 Web extra 和 Chromium；不复制旧 `.venv`。
4. 执行 `ftr backup restore --path /备份目录 --target /一个不存在的新数据目录`。
5. 将 `data_dir` 或 `FTR_DATA_DIR` 指向恢复目录，执行 config show、doctor、task status，再启动工作台核对资料与原件。
6. 需要继续税务任务时，用目标机器的正常浏览器会话重新采集；Cookie 不随备份迁移。

恢复禁止覆盖现有目录。验证失败时保持原运行目录，修复备份来源或选择另一备份。不要把恢复目标指定为正在使用的数据目录。

## 常见故障

| 现象 | 检查与处置 |
|---|---|
| 配置无效或找不到文件 | 使用绝对 FTR_CONFIG；config show 核对覆盖来源；检查字段拼写、类型、重复键与路径 |
| 数据目录正由另一宿主使用 | 核对 CLI/宿主进程，等待或正常停止写入者；不要删除锁文件绕过 |
| 工作台 DATABASE_MISSING | 核对 data_dir，恢复已有资料或先执行明确范围的采集；Web 不创建空库 |
| 空库 | 空结果与缺库不同；核对是否连接到错误目录 |
| 无法监听端口 | 改端口或停止占用进程；核对 host 是否属于本机网卡 |
| 其他电脑打不开 | 使用服务器实际 IP；核对非回环 host、进程和网络端口可达性 |
| 浏览器文件缺失 | 在实际运行解释器中执行 playwright install chromium，或设置合法 executable_path |
| Linux 无显示环境 | 安装 Xvfb/xauth，使用 xvfb-run -a 执行；doctor 的显示变量存在不等于连接已验证 |
| 403 / 验证码 / 登录要求 | 停止并记录来源限制；不自动更换出口、伪造身份或绕过验证 |
| 非公网 DNS 被拒绝 | 核对代理模式；仅有效回环代理有映射网段例外；不恢复废弃 DNS 开关 |
| 请求超时 / 文件过大 / PARTIAL | 查看失败与预算口径，调整允许的运行参数后续跑，保留既有证据 |
| 资料正文或主附件未解析 | 原件可下载，状态继续受限；未实现 Word/Excel/OCR 不得写成已完整解析 |
| 数据库损坏 / 原件哈希失败 | 停止写入，保留故障目录，在新目录恢复已验证备份 |

## 升级与回退

升级前保存已验证备份、安装包版本、锁文件和非敏感配置；在独立安装环境中完成 config validate、doctor 和只读查询核验后，再切换运行入口。包版本当前为 0.1.0，本次配置改造未自行升级版本或发布。

本次不修改数据库结构。旧任务保持兼容；旧命令、FTR_DATA_DIR 和默认数据目录继续可用。代码回退可切换之前安装环境；数据回退在新目录恢复备份。正式 Adapter 发布与自动回退仍未开放。
