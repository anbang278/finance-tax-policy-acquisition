# 财税资料获取插件 PRD

状态：研发进行中。历史原始需求基线见[财税研究 Agent 插件交接文档 v1.0](../history/财税研究%20Agent%20插件%20交接文档%20v1.0.md)及 2026-09-28 的实施计划；当前范围与后续变更以本 PRD 为准。

## 目标

用户通过 Codex 或 Hermes 获取财政部“政策发布”和国家税务总局政策法规库的公开资料，保存可复查原件，区分政策、解读与消息，复核后用于有引用的研究。来源发生结构变化时形成可审查的修复候选。正式发布仍需未来的隔离测试和独立人工批准。

## 已确认范围

- 采集前由用户明确时间范围；可唯一换算的相对区间转为具体起止日期并告知用户。未说明、只说明单侧边界或仅说“最近”等模糊时间时，先反问，不默认采集过去一年。支持指定日期和历史回填；日期口径逐来源显示。
- 两个栏目全部直接条目纳入，类型分别标记；只自动取直接附件，不递归抓取关联页面。
- HTML 与文本 PDF 可解析；Word、Excel、扫描件保留原件并展示内容限制。
- 一份 Python 核心、五个 Skill、Codex 和 Hermes 两套安装清单。
- 本地演示可以采集、存证、复核、检索、研究、生成补丁候选；没有隔离执行环境不运行未知补丁。

## 使用场景

1. 采集指定日期范围的财税资料，看到来源、类型、日期字段原意、附件与质量状态。
2. 研究一个主题时，引用到已验证的资料版本与原件；证据不足时明确列出。
3. 页面变动导致采集失败时，看见失败事实和补丁候选，了解实际验证与发布状态。

## 成功标准

- 两来源能分别完成真实列表、详情和附件路径抽查；网络受限时给出可追踪失败。
- 中断续跑不覆盖证据或重复建资料；旧版本仍可引用。
- 未复核或内容不完整的资料默认不进入正式检索。
- 候选修复止于 `PATCH_PROPOSED`，`repair test` 与 `governed` 明确阻塞。
- Codex 与 Hermes 分别从安装包加载 Skill；加载成功和语义质量分别记录。

## 不在首版

自动税务申报、企业适用性裁决、全网爬取、复杂管理后台、OCR、Word/Excel 提取、生产发布，以及可信隔离环境中的自动候选代码执行。

交付状态使用 `LOCAL_DEMO_ACCEPTED`、`PARTIAL` 或 `BLOCKED`。原交接文档中的 `MVP_ACCEPTED` 仍依赖完整 Level 4 和人工验收。


## 已确认扩展：跨环境应用（2026-09-30）

- 完整说明覆盖用户、部署者、开发者与后续 Agent 接手；项目总入口导航到安装、配置、使用、运维和研发事实。
- macOS、Windows 原生、Linux 使用同一 Python 3.13 核心与外部运行配置；保留旧命令、数据路径及现有工作台。
- 支持团队局域网查询和下载，不增加认证；服务默认仍使用回环监听。
- Linux 无桌面税务采集提供 Chromium + Xvfb 运行方式，源站准入须实测。
- 本次不增加 Docker、定时采集、来源扩展、模型 API 服务或正式发布能力。
- 验收以参数实际生效、无效输入无业务写入、锁与迁移兼容、独立 wheel 运行及分环境证据为准；模拟测试不代替真实跨系统/跨电脑访问。
