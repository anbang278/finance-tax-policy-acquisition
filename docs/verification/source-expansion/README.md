# 公开来源扩展验证汇总

本页为0.1.3的公开汇总，来源状态冻结于2026-11-06；网站后续状态可能变化。

| 项目 | 结果 |
|---|---|
| 目录 | 177项，含36局×4类地方栏目槽位 |
| 具体登记 | 89个栏目，55个具备适配规则 |
| 有界实采 | 37 PASS、8 PARTIAL；132项入口、规则或访问缺口 |
| 保存结果 | 当前结果口径122份正文记录、41份附件原件 |
| 总体验收 | 工程能力已实现，全范围逐源接入PARTIAL |

逐项状态见[栏目矩阵](coverage.md)和[36局矩阵](regional-matrix.md)。PASS只表示限定样本获取及原件检查，不代表历史全量、所有附件可解析或语义审核通过。每次样本最多2页列表、3份正文及所见附件；失败和修复重试单独保存。

已实现受控来源ID、CLI/工作台目录、日期预算预览、冻结快照、公开HTTP/浏览器适配、同主机限速、多来源持久轮转及旧请求/计划兼容。SQLite v7写入迁移前备份，只读页面不迁移。

浏览器DOM和原始响应分别保存；缺原始响应不得进入复核。DOM和非内容资源说明属于collection_notes，实际正文/附件缺口保留limitations；真实三份问答已只读核对可进入人工复核，未提交审核。旧资料状态不因新版本改写。

实采发现并修复空翻页参数、同步限速挤占DOM等待、WebSocket同步关闭重入及中断收尾问题。WS保持不连接上游；不绕过证书、验证码或访问限制。预算司约64MB PDF使用独立100MB样本预算成功保存，其他缺口仍单独记录。

原始网页、浏览器截图、运行日志、隔离数据库和哈希明细保存在开发者本地，未随公开仓库分发。公开回归使用tests/fixtures/public_sources中的自编结构样本，不能作为真实源站证据。旧本机508项回归结果是本轮实施阶段记录；0.1.3发布门禁与修复后的实际结果见[发布验证](../release-0.1.3.md)。

操作与复现入口见[来源目录指南](../../guides/source-catalog.md)，完整源代码及安装包通过GitHub发布页获取。
