# 0.1.3 发布验证

本次版本包含企业所得税专题研究和公开来源扩展。远端基线为0.1.2、`8b5e782`；六处版本源同步到0.1.3。代码发布与实际资料采集、复核、计划启用分别授权。

## 发布范围

- 官方URL补采、政策身份候选、时间与法律关系、逐项证据预审、Wiki候选及研究报告。
- 来源目录、范围快照、公共HTTP/浏览器适配、来源及整批预算、多来源调度和SQLite v7兼容。
- 公开库收录工程代码、操作文档、汇总验证和自编结构夹具。竞品研究、账号界面截图、本机资料库、原始网页及详细运行日志留本地；原始制品不改写。
- sdist采用明确发布白名单，并从干净检出构建；安装包不得包含上述本地资料。原README和实施文档的个性链接修改留在原工作区，发布副本使用仓库相对链接。

## 已知能力边界

2026-11-06的来源目录包含177项，89项有具体登记、55项有适配规则；有界实采37 PASS、8 PARTIAL，其他项为入口、规则或访问缺口。覆盖全国36局的清单不证明全部栏目可采集，也不证明历史全量或财税语义正确。详见[逐来源汇总](source-expansion/README.md)。

36题专题评测及限定官方原件回放只覆盖已注明的证据范围；日常知识启用和Wiki发布仍由使用者审核，详见[专题研究汇总](cit-research-loop/REPORT.md)。
