# 企业所得税专题研究公开汇总

本轮以0.1.2、8b5e782为实现基线，成果随0.1.3发布。专题包括小微企业优惠、研发费用加计扣除、优惠办理与资料留存。

已实现官方URL定向补采、政策身份与镜像记录、主体条件及时间语义、法律关系证据、逐项引用检查、独立预审、Wiki候选预览与研究报告。确定性结论必须绑定可定位证据，材料不足明确显示缺口；日常审核与发布仍由使用者确认。

实施阶段的隔离资料加工产生8条知识候选、4篇Wiki候选及3份研究报告。36题宿主评测中，13项限定文本结论通过、23项待核实；22题企业所得税、14题用于跨税种和法源边界。重点6题重复3次共18条在限定输入内通过。同线程、非盲评和有限原件范围均是限制，不构成全面专业语义验收。

早期定向采集因本机网络路径受限失败，另有6份实际财政部HTML进行隔离回放；后续来源扩展找到正常代理路径并形成独立有界实采结果，见[来源汇总](../source-expansion/README.md)。不同阶段的回放与真实采集不能混为一体。

来源变化演示使用虚构资料，在隔离环境中完成影响定位、修订候选、模拟人工审核发布和影响关闭。没有自动启用实际知识或发布实际Wiki。

原始模型任务包、回答、预审结果、官方原件、截图、竞品研究和本机日志保留本地；本页仅提供公开汇总，不提供这些本地制品的下载承诺。工程回归、迁移恢复、构建和更新检测见[0.1.3发布验证](../release-0.1.3.md)。操作见[专题指南](../../guides/topic-research.md)。
